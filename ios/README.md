# Controle Queijos — iOS

Primeira base SwiftUI para iPhone, alinhada à V7.50 do Android.

## Objetivo
Reproduzir no iOS as funções aprovadas da V7.50:
- Início
- Clientes
- Encomendas
- Entregas
- Produção
- Financeiro
- Backup
- Sincronização

## Estado desta etapa
Esta é a base inicial do aplicativo iOS. O projeto precisa ser aberto/compilado no Xcode em macOS para gerar um app iOS instalável.

Para TestFlight/App Store será necessário configurar a assinatura da Apple (Apple Developer, Bundle ID e certificados/provisioning profile).

A sincronização entre Android e iOS deverá usar o mesmo formato JSON da V7.50.
